# 🎨 منصة معرض الفنون (Art Gallery Platform)

منصة عربية متكاملة واحترافية لعرض ونشر الأعمال الفنية، اللوحات، الرسومات الرقمية، والصور الفوتوغرافية، مبنية بتقنيات حديثة وسريعة ودعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL).

---

## 🌟 الميزات الأساسية

1. **تصميم فني أنيق ومتجاوب (Mobile First):** يدعم الهواتف، التابلت، وأجهزة الكمبيوتر مع أنظمة تخصيص المظهر (كلاسيكي، عصري، داكن فني، ألوان مائية، معرض أبيض).
2. **تسجيل الدخول والتراخيص:** دعم Google Auth, Facebook Auth, والبريد الإلكتروني مع كلمة المرور ببروتوكولات أمان Firebase.
3. **رفع وتخزين الصور:** إمكانية رفع عمل منفرد أو مجموعة أعمال فنية متعددة دفعة واحدة، مع ربط مباشر بـ Cloudinary لحفظ وتحسين جودة الصور أوتوماتيكيًا.
4. **النشر المباشر ونظام المراجعة:** رفع ونشر مباشر بدون مراجعة لصاحب الموقع والمشرفين، ونظام اعتماد ومراجعة للأعمال المقدمة من المستخدمين العاديين.
5. **نظام الإعجابات والتعليقات:** تفاعل آمن في الوقت الفعلي يمنع التكرار ويسمح بإدارة التعليقات.
6. **بطاقات مشاركة وسائل التواصل الاجتماعي (Open Graph SSR):** توليد معاينات ذكية ديناميكية تظهر صورة العمل الفني بدقة عالية بأسلوب البطاقة الكاملة عند المشاركة عبر Facebook, WhatsApp, X (Twitter), Telegram.
7. **نظام الصلاحيات الشامل (Owner / Admin / User):**
   - **Owner (المالك):** إضافة وإزالة المشرفين، التحكم الإداري الشامل، وحماية الحساب.
   - **Admin (المشرف):** مراجعة الأعمال، القبول والرفض، تمييز الأعمال المميزة، وحذف التعليقات.
   - **User (المستخدم):** رفع الأعمال، متابعة حالتها في "أعمالي"، الإعجاب والتعليق.
